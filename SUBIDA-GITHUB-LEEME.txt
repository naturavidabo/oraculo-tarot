ORÁCULO TAROT v0.5.0 — CONTROL RÁPIDO DE SUBIDA

1. Descomprime el ZIP.
2. Sube TODO el contenido de la carpeta oraculo-tarot-pwa-v0.5.0 al repositorio.
3. En GitHub verifica que aparezca la carpeta .github.
4. Entra a .github > workflows y confirma deploy-pages.yml.
5. En Settings > Pages selecciona GitHub Actions.
6. En Actions espera el flujo "Deploy PWA to GitHub Pages".

IMPORTANTE: no es necesario subir v0.1, v0.2, v0.3 o v0.4 antes. v0.5.0 es acumulativa.
