# ORÁCULO TAROT 1.0.0 Beta 6.3 — validación

Objetivo: estabilizar reconocimiento individual antes de reconocimiento múltiple.

Prueba mínima física:
1. El Mago ligeramente descuadrado: registrar puesto, similitud y orientación.
2. Templanza girada/descuadrada sobre fondo uniforme: registrar puesto y similitud sin usar 4 esquinas inicialmente.
3. Hierofante + Templanza juntas: el modo individual debe bloquear el reconocimiento.

Criterio de avance: cartas individuales razonables normalmente Top 1–3 y escena de dos cartas bloqueada.
