# ORÁCULO TAROT 1.0.0 Beta 6.1 — validación

Versión correctiva enfocada exclusivamente en los fallos observados durante pruebas físicas de Beta 6.

## Cambios
- Detector multicarta más conservador para evitar bloquear una sola carta descentrada.
- Regiones de evidencia multicarta casi disjuntas.
- Descriptor que combina imagen completa con núcleo interior.
- Más tolerancia a pequeños desplazamientos, escala y rotación.
- Hipótesis de rescate izquierda/derecha/superior/inferior.

## No modificado
- Orientación derecha/invertida.
- Ajuste manual de cuatro esquinas.
- Selección manual.
- 78 cartas, tiradas, aclaratorias, historial y motor interpretativo.

## Pendiente
La eficacia real de cámara requiere prueba física. Esta validación de código no demuestra precisión fotográfica.
