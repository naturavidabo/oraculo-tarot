# ORÁCULO TAROT 1.0.0 Beta 6.2 — validación

Objetivo: estabilizar reconocimiento individual antes de reconocimiento múltiple.

Cambios verificables por código:
- similitud tolerante a traslación interna;
- rescates ampliados de escala, rotación y posición;
- ranking robusto con menor dependencia de una única variante;
- bloqueo multicarta conservado;
- orientación y corrección manual preservadas.

Validación física requerida: Mago, Templanza y una escena de dos cartas.
